#### Criterios de Selección de Recursos

1. **Alineación curricular**: Cada recurso está vinculado explícitamente a bloques temáticos y objetivos específicos del programa 2151106.

2. **Accesibilidad**: Se priorizan recursos de acceso abierto o con acceso institucional vía UAM, garantizando equidad para toda la comunidad estudiantil.

3. **Actualización**: Se incluyen recursos con mantenimiento activo (documentación oficial, plataformas interactivas) para reflejar prácticas contemporáneas en la industria.

4. **Diversidad pedagógica**: Se combinan recursos teóricos (artículos, libros), prácticos (plataformas interactivas, herramientas) y de actualización (boletines, rankings) para atender distintos estilos de aprendizaje.

5. **Contexto local**: Se incorporan recursos institucionales ([biblioteca digital UAM](https://bidi.uam.mx/)) para fortalecer la pertinencia académica y la identidad universitaria.
